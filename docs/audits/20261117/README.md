# Home Mate 全量范围审计与竞品研究

日期：2026-11-17（北京时间）。状态：**审计发现与改进提案，尚未修复，不是设备验收或里程碑完成声明。**

## 结论

Home Mate 的用途是可自主掌控的家庭语音伙伴：五台 Dot2 各自运行 Rust Core，通过本机 Gateway 处理硬件与音频，NAS 提供可选共享记忆和管理服务，Vue 控制台管理真实服务与设备。它已具有相当完整的工程底座，适合继续迭代；本轮没有发现需要推倒重写的证据。

最主要的问题是**不同模块对同一件事的解释尚未完全一致**：一次话语是否属于同一房间请求、谁拥有当前对话、已开始的收音是否仍有资格、工具是否获准访问记忆、设置是否真的应用、设备是否真的停止。多个局部单元测试成立，但真实生产调用链仍有缺口。优先补齐这些合同，再扩展家庭功能。

六个领域报告共记录 **37 项发现：P1 18 项、P2 18 项、P3 1 项；未证明 P0**。P1 是高优先级、在依赖相关行为或扩大部署前应修复的条件性缺陷，不能解读为五台设备均已发生事故。跨报告相邻问题按不同根因分列，副作用元数据等附属问题没有重复计数。

## 八个重点领域的判断

| 领域 | 已有价值 | 主要不足 |
|---|---|---|
| 架构 | Core/Gateway 分离、模块化单体、工具接口、每机运行边界清楚 | 同一事实分散在多个状态域，跨 Core 所有权与跨模块生效合同缺口 |
| 质量 | 大量 Rust 行为测试、真实前后端、类型检查与构建 | 一些测试只测 helper/CRUD，未覆盖真实拓扑、mount/poll/save 或配置落到设备 |
| 健康度 | A/B 发布、签名、回执、取消身份与可观测性基础 | 迁移中断恢复、恢复出厂清理、慢连接背压、旧文档竞争；无法由健康探活推导全部功能正确 |
| 多房间仲裁 | claim、声压/近端证据、enforce/shadow 结构存在 | 不同请求合并、ASR 路径绕过选举、passive 局部双赢、owner 未跨 Core、撤销不完整 |
| 交互 | generation/request 身份、显式取消、答案尾音与普通提示区分 | 跟随窗到期吞已开始输入、停止回执假确认、上下文 TTL 未接实际历史 |
| AEC/KWS/跟随窗 | 7 麦 AEC、输出历史参考重建、KWS sidecar、局部低延迟停止 | 零参考虚报健康、校准重复补偿、声学 CRUD 未应用、采集完整性与保护开关边界 |
| 大脑/记忆/工具 | 自有执行循环、来源记录、可替换服务、动态工具接入 | 记忆作用域执行权限、可信确认、观察入队/删除传播、动态名称往返 |
| UIUX/Logo/后台 | 真实管理 API、统一主题、中英键完整性、SVG 标志、部分表单回读 | 人格初始未加载、轮询覆盖草稿、身份初始化、旧状态新时间；家庭日常入口不足 |

Logo 源码一致性、主题适配和可访问名称具有基础；没有证据支持仅因技术审计就重画 Logo。小尺寸、明暗背景、手机视口和屏幕阅读器仍需实际渲染验证。后续优先改善信息结构与行为反馈。

## 建议修复批次

| 顺序 | 批次与状态所有者 | 最小验收边界 |
|---|---|---|
| 1 | 数据与权限：Store、记忆服务、工具执行上下文 | 原子迁移；reset 后有效 prompt 清洁；跨 scope 读写受限；可信确认；NAS 删除完整传播 |
| 2 | 分布式仲裁：共同 claim/round/最终 winner 与 owner 合同 | 三 Core 真实拓扑；独立同时请求都完成；串音仅一个赢家；ASR/passive/KWS 一致；迟到撤销、退场归属 |
| 3 | 音频与配置：Gateway 有效声学事实、Core 配置投影、Fleet allowlist | 非零校准只计一次；坏参考必降级；每机参数不串台；配置有有效值回执；采集短读与慢连接有界 |
| 4 | 会话与输出：输入 lease、上下文截止、typed stop receipt | 窗内输入跨截止仍可完成；显式取消仍有效；未知不说已停稳；真实媒体终止保护；context 到期不再带旧历史 |
| 5 | 控制台与文档：server snapshot/draft/freshness | 首次读取、失败重试、dirty 草稿、多页面并发、准确成功时间；同步当前入口状态 |

批次可在独立分支并行，但接口交汇处先共同定合同。每批都应有管理 API、必要 UI、行为验证和独立验收。修复不代表已部署：需要受影响的构建与一台 canary，再按明确场景验收，最后由所有者授权五台更新。不要复制逐机声学值，不重做已完成的 serial69 OTA。

## 竞品对比与非 bug 产品增量

第二队覆盖 Home Assistant Assist/Voice PE、Alexa+/Echo、Gemini for Home/Nest、HomePod、Xiaomi Sound；14 组官方资料并由另一名研究 Agent 复核。详见 [产品对标](product-benchmark.md) 与 [研究复核](benchmark-review.md)。官方支持/宣传不是同环境实测，地区、语言、账号与硬件限制已写入分报告。

我们的结构潜力是自主执行逻辑、可替换服务、可管理记忆和可追溯事实；“完全本地”并非独有，Home Assistant 已支持本地管线。主要差距在成套接入、普通家庭的使用入口、手机协作及家庭事务管理。没有证据宣称唤醒、AEC 或多房效果优于竞品。

以下 **8 个新增方向**均独立于上述缺陷修复；第 9 项为已规划 W4c 的产品扩展，单列不冒充新路线。

| 方向 | 家人能直接获得什么 | 建议阶段 |
|---|---|---|
| 能力中心与接入配方 | 看清当前能做什么，按引导接入 HA/音乐/自有工具并试用 | 首批 |
| 手机任务卡与操作回执 | 手机继续选择、确认、取消和查看一次语音任务；首版限管理员受控确认 | 首批 |
